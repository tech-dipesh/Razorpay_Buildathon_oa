# vaada
the Project will build as a Monotolith Architecture which the shared components will be within a single packages while the indepdepent system will be run.

*A promise, written down.*
A promise-to-pay tracker for personal loans between people who trust each
other — friends, family, neighbours. India's personal lending market runs
almost entirely on verbal agreements with no record and no recourse. Vaada
never lends money itself; it documents the promise and helps recover it
when it slips, with the same visibility a bank loan has.
